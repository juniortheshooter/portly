# Portly — Developer Notes (`local-project-manager`)

## Architecture Overview
Portly (formerly DevDeck) is a local development studio and native desktop application (`http://localhost:4567`) built to manage, launch, monitor, and log local web applications and websites from a single GUI.

### Project Structure
- `server.js` — Cross-platform Node.js HTTP server (`node:http`, `node:net`, `node:os`, `node:child_process`, `node:fs`), OS detection (`GET /api/system`), project path inspection & `~` tilde expansion, stack analyzer, Windows (`cmd.exe` + `taskkill /T /F`) and POSIX (`$SHELL -c` + process-group `SIGTERM`/`SIGKILL`) lifecycle management, native OS folder pickers & file manager launchers, SSE stream (`/api/stream`), and settings/project persistence.
- `desktop-app.js` — Zero-dependency standalone multi-OS desktop window runner (`--app=http://localhost:4567` via Chrome/Edge/Brave/Chromium on Windows, macOS, and Linux, with OS browser fallback).
- `electron-main.js` — Native Electron desktop wrapper (`BrowserWindow`, `shell.openExternal`, packaged `userData` support, clean server teardown on quit) paired with `electron-builder` targets for Windows (`.exe` NSIS/portable), macOS (`.dmg`/`.zip`), and Linux (`.AppImage`/`.deb`).
- `install-app.js` — Cross-platform launcher & app bundle builder generating `Start-Project-Manager.bat`, `Start-DevDeck-App.bat`, silent `DevDeck-Desktop.vbs`, `DevDeck.lnk` (Windows), `Start-DevDeck.command` & `DevDeck.app` bundle (macOS), and `start-devdeck.sh` & `DevDeck.desktop` (Linux).
- `static-server.js` — Built-in zero-dependency static file server used automatically for plain `index.html` projects without `package.json`.
- `public/index.html` — Application shell, sidebar navigation (with OS badge and Desktop App Window button), KPI metrics, workspace split/card/table views, live log console, project import modal, and user settings modal with Multi-OS desktop controls.
- `public/styles.css` — Soft iOS / macOS Sonoma glassmorphic design system with Light & Dark themes, entrance/exit page transitions, expandable project cards, Multi-OS badge/action styling, and responsive full-width layout.
- `public/app.js` — Client state management, `/api/system` OS adaptation, SSE event streaming, inline SVG icon helpers, expandable card toggles, theme/settings synchronization, `Start & Open` tab launching, and standalone desktop app actions.
- `test-multi-os.js` — Automated syntax, OS helper, launcher generation, and ephemeral HTTP API verification suite.
- `data/projects.json` — Registered projects, detected metadata, commands, and ports.
- `data/settings.json` — User preferences (`userName`, `theme`, `defaultExpanded`, `onboarded`).
- `logs/<project-id>.log` — Persistent timestamped `stdout`, `stderr`, and `system` logs per project.
- Cross-Platform Launchers: `Start-Project-Manager.bat`, `Start-DevDeck-App.bat`, `DevDeck-Desktop.vbs`, `DevDeck.lnk`, `Start-DevDeck.command`, `start-devdeck.sh`, `DevDeck.app`, `DevDeck.desktop`.

## Development Changelog

### Phase 1: Core Process Manager & Log Streaming
- Built `server.js` using Node.js v24 built-in modules only (no external `npm install` needed).
- Avoided Windows PowerShell `npm.ps1` execution policy blocks by spawning commands via `cmd.exe /d /s /c`.
- Added Windows process-tree termination via `taskkill /PID <pid> /T /F` so stopping a server never leaves orphaned Node/Vite child processes holding ports.
- Implemented persistent per-project log files (`logs/<id>.log`) with ANSI escape code stripping and real-time Server-Sent Events (`/api/stream`).
- Built single-path inspection (`POST /api/inspect`), Windows native folder browser (`POST /api/pick-folder`), and bulk path import (`POST /api/projects/bulk`) supporting `.txt`, `.json`, `.csv` uploads and subfolder discovery.

### Phase 2: Soft iOS / macOS Glassmorphic UI Redesign
- Redesigned the UI into a bright, frosted glassmorphic dashboard inspired by Soft iOS / macOS Sonoma aesthetics with pastel ambient blobs, left workspace sidebar (`⌘K` quick search, filter counts, quick-jump list), 3 KPI cards with curved SVG sparklines, and light-mode log viewer.
- Added tactile green/gray iOS toggle switches (`role="switch"`) on cards and table rows, clean inline SVG icons, and 3 switchable layouts (`Split Console`, `Cards`, `Table`).

### Phase 3: Smart Stack Recognition & Auto-Deploy Engine
- Investigated why `example-nextjs-app` (Next.js 15) booted while `example-express-vite-app` (Express + Vite middleware via `tsx watch`) stalled: on Node.js v24 on Windows, `tsx watch` deadlocked IPC watching when dynamically importing `vite` middleware, whereas `npx tsx src/server/index.ts` boots cleanly in ~2–3 seconds with Vite middleware handling HMR.
- Added deep stack analysis (`analyzeNodePackage`, `analyzePythonProject`) detecting language (`TypeScript`, `JavaScript`, `Python`, `HTML / CSS`), program type, framework (`Express + Vite`, `Next.js`, `Vite`, `Astro`, `Remix`, `Nuxt`, `SvelteKit`, `Angular`, `Django`, `FastAPI`, `Flask`, `Streamlit`, `Static HTML`), tech stack chips, and default port.
- Added automatic port conflict resolution (`isPortListening` checking both `127.0.0.1` and `::1`, `findAvailablePort`) and active TCP port probing (`startActivePortProbe`) so simultaneous multi-app launches (e.g., `example-express-vite-app` on `:3000` and `example-nextjs-app` on `:3001`) succeed without collisions and expose `Open localhost:<port>` and `Start & Open` new-tab controls.
